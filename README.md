# kicad-board-design

Design, edit or review KiCad schematics and PCB layouts with engineering calculations, SI/PI, EMC, thermal, mechanical and manufacturing checks.

This is an agent skill: `SKILL.md` tells an AI coding agent such as Claude Code when to use it and which steps to follow.
